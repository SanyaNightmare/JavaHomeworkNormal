 Домашнее задание 8 — Reflection API и аннотации

Java 17, Maven, JUnit 5. Пакет `hw8`.

- `NotNull`, `Size`, `Range`, `Email` — аннотации (должны быть отдельными файлами по условию).
- `Validator` — проверяет поля, включая приватные и унаследованные.
- `ValidationError`, `ValidationResult` — результаты проверки.
- `ValidationConfigurationException` — ошибка некорректной разметки.
- `Main` — небольшой пример запуска.
- `src/test/java/hw8/ValidatorTest.java` — тесты.

Откройте `pom.xml` в IntelliJ IDEA как Maven-проект. Тесты: `mvn test`. Пример: запустите `Main.main()`.
